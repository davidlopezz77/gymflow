# Briefing de GymFlow

## Client

Club Esportiu Turó, gimnàs de barri amb 1.200 socis, 3 sales i 40 classes dirigides setmanals.

## Problema actual

Les reserves es fan per telèfon i en un full de càlcul. Hi ha classes plenes amb gent que no es presenta.

## Objectius del producte

1. Reduir un 30% les places buides a les classes dirigides mitjançant un sistema de reserves i cancel·lacions.
2. Reduir un 50% el temps que dedica recepció a gestionar les reserves dels socis.
3. Permetre que el 90% dels socis puguin reservar una classe en menys d'un minut.

## Públic objectiu

- **Interfície de Soci:** adreçada als socis del gimnàs que volen consultar les activitats disponibles, veure els horaris i reservar o cancel·lar classes des del mòbil de manera ràpida i senzilla.

- **Interfície de Recepció:** adreçada als treballadors i administradors del gimnàs que necessiten gestionar les activitats dirigides, controlar les reserves, consultar les places disponibles i administrar els horaris.

## Requisits funcionals

### Interfície de Recepció

1. Gestionar les activitats dirigides, podent crear, modificar i eliminar classes.
2. Consultar i gestionar les reserves dels socis.
3. Controlar l'aforament de cada activitat i les places disponibles.
4. Consultar les llistes de socis inscrits a cada classe.

### Interfície de Soci

1. Consultar les activitats dirigides i els seus horaris.
2. Reservar una plaça en una activitat disponible.
3. Cancel·lar una reserva existent.
4. Consultar les reserves realitzades i les places disponibles.

## Restriccions

Accessibilitat WCAG 2.2 AA, funcionament en mòbil, idioma català (amb previsió per al castellà i l'anglès).

## Funcionalitats futures

Exportar informes en PDF, ajuda contextual, mode entrenament amb veu i càmera.
